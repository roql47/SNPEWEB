3. 외부 자료 필요 항목
========================================

[디자인팀 필요 자료]

  1) 로고 파일
     담당: 디자인팀
     필요: 심볼 제거 + 그레이 컬러 버전 (SVG/PNG)
     비고: PDF 원본 가능

  2) 중간 섹션 이미지
     담당: 이사님
     필요: 각 페이지 중간에 들어갈 사진/이미지 소스 목록
     비고: 이사님이 어디에 뭐 들어갈지 정리 예정

[미디어팀 필요 자료]

  3) 메인 배너 AI 영상
     담당: 미디어팀 (김동필+)
     필요: 5초x3개 또는 15초x1개 AI 생성 영상
     비고: Kling 3.0 / Hixfield 활용, 스토리보드 기획 선행

  4) 운동 기본동작 AI 이미지
     담당: 미디어팀
     필요: 기존 사진 얼굴/옷 교체한 AI 이미지
     비고: CTLSC 동작 사진 기반

  5) YouTube 영상 선별
     담당: 민영 PD
     필요: 운동영상 페이지에 넣을 YouTube 영상 목록
     비고: 루틴 영상, CTLSC 영상 등

[교육팀 필요 자료]

  6) 연혁 2024~2025
     담당: 교육팀
     필요: 2024~2025 주요 이벤트 데이터
     비고: 사회과대 석사과정, 국민대 개설, 잠실점 등

  7) 인증강사 목록
     담당: 교육팀
     필요: 현재 활동 인증강사 리스트 (이름, 지역, 레벨, 센터)
     비고: 6개월마다 변동 → 관리자 CRUD 필요

  8) 임산부 과정 커리큘럼
     담당: 교육팀
     필요: 임산부 과정 소개 텍스트, 대상, 수업 구성 등
     비고: 회의에서 추가 언급됨

[운영팀 필요 사항]

  9) 각 센터 네이버 예약 URL (선택)
     담당: 운영팀
     필요: 정확한 네이버 플레이스 URL (현재 자동검색 URL로 동작 중)
     비고: 관리자 패널에서 개별 교체 가능

  10) CS 담당자 지정
      담당: 서 팀장
      필요: 문의 접수 관리 담당 1명
      비고: 기업특강, 개설문의 등 접수 처리

  11) 관리자 계정 운영 담당
      담당: 운영팀
      필요: 센터/인증강사 등 정기 업데이트 담당
      비고: 관리자 패널 사용 교육 필요


========================================
4. 진행 우선순위 로드맵
========================================

[Phase 1 — 즉시 가능 (개발자 단독)]
  1. 인증강사 관리자 CRUD 구현
  2. 메인 배너 멀티 슬라이드 구조 구현
  3. 임산부 과정 페이지 생성 (기본 틀)
  4. 코드 스플리팅

[Phase 2 — 자료 수령 후 적용]
  1. 로고 교체 (디자인팀 → SVG/PNG)
  2. 연혁 데이터 추가 (교육팀 → 텍스트)
  3. 인증강사 초기 데이터 입력 (교육팀 → 리스트)

[Phase 3 — 미디어 콘텐츠 교체]
  1. 메인 배너 AI 영상 교체 (미디어팀 → 영상 파일)
  2. 기본동작 AI 이미지 교체 (미디어팀 → 이미지)
  3. 운동영상 YouTube 링크 교체 (PD → URL 목록)
  4. 각 페이지 중간 이미지 교체 (이사님 → 소스)

[Phase 4 — 고도화]
  1. 백엔드 구축 (Supabase/Firebase 전환)
  2. 센터별 정확한 네이버 플레이스 URL 교체
  3. SEO 최적화
  4. S 시스템 연동 (추후 논의)
